# E2E: No-Code Builder

Draft scenario for a non-programmer using AI Builder OS to create a personal tool with agentic coding help.

## Expected Path

```text
builder-router -> builder-frame -> builder-agent-task
```

## Required Behavior

- Explain in human-readable Chinese.
- Generate agent-executable instructions.
- Do not assume the user understands code internals.
- Include verification and human approval gates.
