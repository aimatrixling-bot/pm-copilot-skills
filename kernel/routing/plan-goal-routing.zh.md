# Plan / Goal 路由

这份策略来自已安装的 Plan Goal Coach，并提升为 Builder Kernel 的共享规则。

## 决策规则

| 场景 | 推荐模式 |
| --- | --- |
| 小而清楚的一次性任务 | Prompt |
| 目标模糊、代码库未知或取舍不清楚 | Plan |
| 目标、边界、完成标准和验证方式都清楚 | Goal |
| 大型系统、迁移、原型套件或多模块重构 | Plan -> Goal |
| 缺少业务、安全、权限、数据或生产决策 | Ask first |

## Goal 就绪条件

只有同时具备以下要素，任务才适合进入 Goal：

- 具体目标；
- 有边界的范围和 non-goals；
- 已知上下文来源；
- 完成标准；
- 验证方式；
- 停止条件；
- 针对高风险操作的人工批准点。

## Plan 输出要求

大型任务的 Plan 必须产出一个可以直接复制执行的 Milestone 1 Goal。
