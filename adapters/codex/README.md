# Codex Adapter

This adapter documents how AI Builder OS projects to Codex.

## Invocation

- Explicit skill mention: `$builder-agent-task`
- Natural language routing: rely on skill `description`
- Goal workflows: use copy-ready `/goal` prompts generated by `builder-plan-goal` or `builder-agent-task`

## M3.2 Package Surface

`install.js codex` installs the pure AI Builder OS active surface into the Codex user-level skills directory.

Package metadata is declared in `skill-pack.json` and `agents/openai.yaml`. The npm package id remains `pm-copilot-skills` for compatibility; `ai-builder-os` is the product identity and command alias.

## M3.3 Export

Adapter manifest: `adapters/codex/adapter.json`

```bash
npm run export:runtime -- --target codex --out ".\dist\ai-builder-os\codex" --clean
```

Layout: `flat-skill-root`. Each exported builder skill embeds shared `kernel`, `references`, `templates`, and `adapters` resources.
