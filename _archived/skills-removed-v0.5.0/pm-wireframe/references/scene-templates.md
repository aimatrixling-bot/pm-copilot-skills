# 场景线框模板差异化指南

> **用途**：为 pm-wireframe 的 6 大场景提供线框结构和元素选择指南。
> **原则来源**：`scene-rules.md` 场景差异化矩阵 + 5 条核心原则（P1~P5）。
> **与 pm-prototype 的关系**：pm-wireframe 定结构，pm-prototype 定视觉。本文件定义线框级差异，视觉级差异见 `pm-prototype/references/scene-rules.md`。

---

## 场景速查表

| 场景 | 产品姿态 | 核心导航 | 信息密度 | 表单策略 | 线框重点 |
|------|----------|----------|----------|----------|----------|
| B2B-PC | Sovereign | 侧边栏 + 面包屑 | 高 | 多列 + 行内编辑 | 数据密度 + 操作效率 |
| B2B-Mobile | Transient | 底部 Tab + 筛选栏 | 中 | 单列向导 + 选择>输入 | 快速完成单一任务 |
| C2C-PC | Sovereign/Transient | 顶部导航 + 搜索 | 中 | 2 列 + 浮动标签 | 品牌叙事 + 转化漏斗 |
| C2C-Mobile | Transient | 底部 Tab(4-5项) | 低 | 全宽单列 + 大按钮 | 即时满足 + 手势驱动 |
| Tablet-Landscape | Sovereign 子集 | 侧边栏(可收起) + 分屏 | 高→中 | 2 列 + 分屏预览 | 触控+内容双需求 |
| Tablet-Portrait | Transient 子集 | 抽屉侧边栏 | 中→低 | 单列卡片分组 | 阅读优先 |

## B2B-PC 线框模板

### 布局结构

```
┌──────────────────────────────────────────────────────┐
│  [Logo]  [面包屑: 首页 > 患者管理 > 列表]    [👤 头像] │  ← 顶部栏 48-56px
├──────────┬───────────────────────────────────────────┤
│ ▸ 患者管理 │  [搜索框] [筛选▼] [排序▼] [+ 新增] [导出]  │  ← 工具栏
│   列表    │ ┌─────────────────────────────────────────┐│
│   详情    │ │ # │ 姓名    │ 科室  │ 状态  │ 预约日期    ││
│ ▸ 预约管理 │ │ 1 │ 张明远  │ 眼科  │ 已预约 │ 06-10      ││  ← 表格：行高 36-40px
│   日历    │ │ 2 │ 李思琪  │ 骨科  │ 待确认 │ 06-11      ││     一屏 20+ 行
│   列表    │ │ 3 │ ...     │ ...  │ ...   │ ...        ││
│ ▸ 数据报表 │ └─────────────────────────────────────────┘│
│           │  [分页: < 1 2 3 ... 50 >] [每页 25 条▼]    │
│           │  [已选 3 项] [批量删除] [批量导出]            │
├──────────┴───────────────────────────────────────────┤
│  状态栏: 共 1,247 条记录 | 最后更新 10:30              │
└──────────────────────────────────────────────────────┘
```

### 核心规则

| 维度 | 规则 |
|------|------|
| 侧边栏 | 固定宽度 200-260px，5-7 个主导航项，当前项高亮 |
| 表格 | 行高 36-40px，支持排序/筛选/列自定义，一屏 ≥20 行 |
| 操作区 | 工具栏在表格上方，主操作（新增）视觉突出 |
| 快捷键 | ⌘K 命令面板，⌘F 聚焦搜索，批量操作用复选框 |
| 反馈 | Toast(轻) → 行内消息(中) → Modal(重) |

### 标准页面类型

1. **列表页**：筛选栏 + 数据表格 + 批量操作
2. **详情页**：左侧详情面板 + 右侧操作区/关联数据
3. **表单页**：Tab 分组 + 多列布局(2-4列) + 底部固定操作栏
4. **Dashboard**：指标卡(3-4个) + 图表(2个) + 表格

## B2B-Mobile 线框模板

### 布局结构

```
┌────────────────────┐
│ [☰] 患者管理  [🔍] │  ← 顶部栏 44-56px
├────────────────────┤
│ [全部▼] [今日▼]    │  ← 筛选栏
│ ┌────────────────┐ │
│ │ 张明远          │ │
│ │ 眼科 · 预约 06-10│ │  ← 卡片列表：一屏 5-8 条
│ │          [详情>]│ │
│ └────────────────┘ │
│ ┌────────────────┐ │
│ │ 李思琪          │ │
│ │ 骨科 · 待确认   │ │
│ │          [详情>]│ │
│ └────────────────┘ │
│                    │
├────────────────────┤
│ [首页] [患者] [+] [日历] [我的] │ ← 底部 Tab 3-5项
└────────────────────┘
```

### 核心规则

| 维度 | 规则 |
|------|------|
| 导航 | 底部 Tab(3-5项)，更多用汉堡菜单 |
| 数据展示 | 卡片摘要 → 点击进入详情，一屏 5-8 条 |
| 表单 | 单列堆叠，分步向导，选择>输入（P3 枚举优先） |
| 触控 | 最小 44×44px（P2），按钮间距 ≥8px |
| 操作 | 滑动删除、下拉刷新、底部操作栏 |

### 表单策略：枚举优先

```
移动端表单控件优先级：
Select(下拉选择) > Radio(单选) > Switch(开关) > Input(文本输入)

每个文本输入框 ≈ 移动端表单完成率下降 ~5%
```

## C2C-PC 线框模板

### 布局结构

```
┌──────────────────────────────────────────────────────┐
│  [Logo]  [首页 商品 分类 社区]     [🔍 搜索...] [🛒] │  ← 顶部导航
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌──────────────────────────────────────────────┐    │
│  │              Hero Banner                      │    │  ← 品牌视觉区
│  │         新品上市 · 夏日特惠                     │    │
│  │         [立即选购]                              │    │
│  └──────────────────────────────────────────────┘    │
│                                                      │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                       │
│  │ 📷 │ │ 📷 │ │ 📷 │ │ 📷 │                       │  ← 商品网格 3-4列
│  │ 商品 │ │ 商品 │ │ 商品 │ │ 商品 │                       │
│  │ ¥299│ │ ¥199│ │ ¥459│ │ ¥129│                       │
│  └────┘ └────┘ └────┘ └────┘                       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 核心规则

| 维度 | 规则 |
|------|------|
| 导航 | 顶部导航 + 搜索 + 购物车，Mega Menu 可选 |
| 布局 | 图文混排，留白适度（P1 Transient 密度） |
| 表单 | 2 列布局，浮动标签，实时验证 |
| 交互 | Hover 预览，视觉叙事，转化漏斗优化 |
| 触控 | 32×32px 最小，图标按钮 36px |

### 标准页面类型

1. **首页**：Hero + 分类入口 + 商品网格 + 社会证明
2. **列表页**：筛选侧栏 + 商品网格(3-4列) + 排序
3. **详情页**：大图 + 规格选择 + 加入购物车 + 评价
4. **结算页**：分步向导(地址→支付→确认) + 进度条

## C2C-Mobile 线框模板

### 布局结构

```
┌────────────────────┐
│ [←] 商品详情 [♡][⊕]│  ← 顶部栏
├────────────────────┤
│ ┌────────────────┐ │
│ │                │ │
│ │   [商品大图]    │ │  ← 单图全宽展示
│ │                │ │
│ └────────────────┘ │
│                    │
│  ¥299  原价 ¥599   │  ← 价格区
│  夏日限定款 · 已售 2.3k │
│                    │
│  规格: [白色] [黑色] │  ← SKU 选择器(非文本输入)
│  数量: [- 1 +]      │  ← Stepper(非手动输入)
│                    │
├────────────────────┤
│ [加入购物车]  [立即购买]│  ← 底部固定操作栏 48px
└────────────────────┘
```

### 核心规则

| 维度 | 规则 |
|------|------|
| 导航 | 底部 Tab(4-5项)，内页顶部返回+操作 |
| 信息密度 | 低——每屏一个核心操作，单任务聚焦 |
| 表单 | 全宽单列，大输入框(≥44px)，下一步式 |
| 交互 | 手势驱动(左滑/下拉)，大按钮(≥44px) |
| 操作栏 | 底部固定操作栏 48px，主 CTA 视觉突出 |

### C 端移动端特殊规则

- 下拉刷新 > 按钮
- 无限滚动 > 分页
- 大图 + 少文字（与 B 端完全相反）
- 支付成功页必须是独立页面（不是弹窗）——Peak-End Rule

## Tablet-Landscape 线框模板

### 布局结构

```
┌──────────────────────────────────────────────────────────┐
│  [Logo]  [导航项...]                    [🔍] [👤] [⚙️]    │
├───────────┬──────────────────────┬───────────────────────┤
│ ▸ 概览     │  ┌──────────────┐    │                       │
│ ▸ 列表     │  │ 患者列表      │    │  患者详情              │  ← 分屏视图
│ ▸ 日历     │  │ 张明远  眼科  │    │  ─────────            │     左列表+右详情
│ ▸ 报表     │  │ 李思琪  骨科  │    │  姓名: 张明远          │
│            │  │ ...          │    │  科室: 眼科            │
│            │  └──────────────┘    │  预约: 06-10 10:00    │
│            │                      │  [编辑] [预约] [删除]  │
└───────────┴──────────────────────┴───────────────────────┘
```

### 核心规则

| 维度 | 规则 |
|------|------|
| 导航 | 侧边栏(可收起) + 顶部导航 + Split View |
| 布局 | 保留桌面结构（表格、侧边栏），触控目标放大到 44px |
| 分屏 | Master-Detail 模式：左列表 + 右详情 |
| 表单 | 2 列布局，侧边预览，表单+详情分屏 |
| 触控 | 所有触控目标 ≥44×44px，分屏拖拽手柄 20px 宽 |

## Tablet-Portrait 线框模板

### 布局结构

```
┌────────────────────────────┐
│  [☰]  页面标题  [🔍] [⚙️]  │  ← 顶部栏(含汉堡菜单)
├────────────────────────────┤
│                            │
│  ┌───────┐ ┌───────┐      │
│  │ 📷    │ │ 📷    │      │  ← 双列卡片流
│  │ 商品1 │ │ 商品2 │      │     利用宽度展示双列
│  └───────┘ └───────┘      │
│  ┌───────┐ ┌───────┐      │
│  │ 📷    │ │ 📷    │      │
│  │ 商品3 │ │ 商品4 │      │
│  └───────┘ └───────┘      │
│                            │
├────────────────────────────┤
│       [底部操作栏]          │
└────────────────────────────┘
```

### 核心规则

| 维度 | 规则 |
|------|------|
| 导航 | 抽屉式侧边栏 + 顶部导航 |
| 布局 | 类似手机但利用宽度展示双列卡片 |
| 表单 | 单列，卡片分组，分步向导 |
| 触控 | 按钮>手势（医疗/专业场景 P2 严格） |
| 操作 | 底部操作栏（类似移动端） |

## 跨场景通用规则

以下规则适用于所有场景，源自 P1~P5 核心原则：

| 原则 | 通用线框规则 |
|------|-------------|
| P1 密度匹配 | Sovereign 场景（B 端 PC）高密度优先；Transient 场景（C 端 Mobile）低密度优先 |
| P2 触控目标 | 所有可交互元素最小尺寸 28px(PC)/44px(移动+平板) |
| P3 枚举优先 | 移动端表单：Select > Radio > Switch > Input |
| P4 状态双编码 | 状态必须颜色+文字（+图标更好），不能仅靠颜色 |
| P5 流程完整 | 从入口到目标达成的完整路径，不能跳步 |
