## 1. AI 交互模式选择

```
产品核心价值是什么？
│
├─ 精准信息获取（搜索/问答）
│   └─ → P-INT-05 直接输出 + P-INT-10 引用透明度
│       例：Perplexity、Google AI Overviews
│
├─ 内容创作/编辑
│   └─ → P-INT-07 可编辑输出 + P-INT-16 版本回溯
│       例：ChatGPT Canvas、Notion AI
│
├─ 专业任务执行（编码/分析/设计）
│   └─ → P-INT-09 展示工作过程 + P-INT-13 人在回路
│       例：Claude Code、Cursor、Devin
│
├─ 通用对话/助手
│   └─ → P-INT-06 流式输出 + P-INT-11 不确定性展示
│       例：ChatGPT、Claude
│
└─ 工作流自动化
    └─ → P-INT-02 结构化表单输入 + P-INT-14 人在环上
        例：Coze、Gumloop、Zapier AI
```

## 2. 输入模式选择

```
用户如何表达需求？
│
├─ 自然描述即可（意图清晰）
│   └─ → P-INT-01 自然语言输入
│
├─ 需要精确参数（减少歧义）
│   ├─ 参数类型固定
│   │   └─ → P-INT-02 结构化表单输入
│   └─ 参数类型灵活
│       └─ → P-INT-01 自然语言 + 结构化混合
│
├─ 涉及非文本内容（图片/文件/代码）
│   └─ → P-INT-03 多模态输入
│
└─ 用户已在工作上下文中
    └─ → P-INT-04 上下文感知输入
```

## 3. 输出模式选择

```
输出用途是什么？
│
├─ 给用户阅读
│   ├─ 需要即时反馈
│   │   └─ → P-INT-06 流式输出
│   └─ 需要后续编辑
│       └─ → P-INT-07 可编辑输出
│
├─ 给系统消费（API/管道）
│   └─ → P-INT-08 结构化输出
│
├─ 需要验证可信度
│   └─ → P-INT-10 引用透明度 + P-INT-12 来源视觉区分
│
└─ 简单问答
    └─ → P-INT-05 直接输出
```

## 4. 人机协作模式选择

```
操作的风险等级？
│
├─ 🔴 高风险（不可逆/影响他人/资金）
│   └─ → P-INT-13 人在回路（HITL）
│       例：删除数据、发送消息、提交代码
│
├─ 🟡 中风险（可回退但成本高）
│   └─ → P-INT-15 渐进信任轨迹
│       首次确认 → 习惯后自动 → 随时可回退
│
└─ 🟢 低风险（可回退/仅影响自己）
    └─ → P-INT-14 人在环上（HOTL）
        AI 自主执行，人类可随时介入
```

## 5. 信任建立策略选择

```
用户的信任水平？
│
├─ 初次使用（低信任）
│   ├─ → P-INT-09 展示工作过程
│   ├─ → P-INT-10 引用透明度
│   ├─ → P-INT-11 不确定性展示
│   └─ → P-INT-15 渐进信任（首次确认）
│
├─ 日常使用（中信任）
│   ├─ → P-INT-12 来源视觉区分
│   └─ → P-INT-15 渐进信任（自动执行）
│
└─ 重度使用（高信任）
    ├─ → P-INT-14 人在环上（自主执行）
    └─ → P-INT-16 版本回溯（安全网）
```

## 6. 错误恢复策略选择

```
错误类型？
│
├─ 方向错误（AI 理解错了意图）
│   └─ → P-INT-17 重新生成（完全重来）
│
├─ 细节错误（方向对但内容需要调整）
│   └─ → P-INT-07 可编辑输出（就地修改）
│
├─ 过程错误（AI 做了不该做的事）
│   └─ → P-INT-16 版本回溯（回退到之前状态）
│
└─ 累积偏移（多步操作后偏离目标）
    └─ → P-INT-16 版本回溯 + P-INT-13 人在回路
        回退到检查点，重新设置方向
```

## 7. 评估指标选择

```
评估维度？
│
├─ 回答质量
│   ├─ → 准确率（事实正确性）
│   ├─ → 完整性（是否覆盖用户需求）
│   └─ → 引用质量（来源可信度）
│
├─ 用户体验
│   ├─ → 满意度（CSAT/NPS）
│   ├─ → 任务完成率
│   └─ → 首次交互成功率
│
├─ 效率
│   ├─ → 首次响应时间
│   ├─ → 任务完成时间
│   └─ → 编辑轮次（越少越好）
│
├─ 信任度
│   ├─ → 信任评分（用户调研）
│   ├─ → 幻觉率（AI 编造内容的比例）
│   └─ → 上下文保持率（长对话一致性）
│
└─ 行为
    ├─ → 参与度（使用频率/时长）
    ├─ → 留存率（7 天/30 天）
    └─ → 推荐率（NPS）
```
