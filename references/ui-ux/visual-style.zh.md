# 视觉风格规范

视觉规范用于约束信息表达、可读性和一致性，不追求统一成固定品牌系统。

## 风格原则

- 产品工具界面应安静、清晰、可扫描。
- 视觉层级服务于业务优先级。
- 避免一页内出现多套风格语言。
- 避免无意义装饰压过信息和操作。
- 当已有项目风格存在时，优先沿用。

## 排版

- 标题层级要少而清楚。
- 正文字号和行高应保证长文本可读。
- 表格、列表、表单等密集信息区域不使用过大标题。
- 按钮、标签、字段文案不能溢出容器。

## 色彩

- 颜色必须有语义：主操作、成功、警告、错误、禁用、信息。
- 不只用颜色表达状态，必要时配合文字或图标。
- 避免大面积单一色系造成疲劳。
- 错误和危险操作必须明显但不误导。

## 间距和布局

- 同类元素使用一致间距。
- 页面主要区域应支持扫描、比较和重复操作。
- 固定格式元素应有稳定尺寸，避免 hover、loading、动态文案造成布局跳动。
- 不要把工具界面做成营销式 hero 页面，除非场景明确需要。

## 响应式

- 必须至少说明桌面和移动端关键布局。
- 移动端不能让主操作、表单字段、错误信息或导航互相遮挡。
- 表格在小屏应说明横向滚动、卡片化或列裁剪策略。
- 复杂工作台可以优先桌面，但必须说明移动端最低可接受表现。

## 可访问性基础

- 交互元素要有可理解标签。
- 焦点、禁用、错误、选中状态应可识别。
- 文本对比度应满足基本可读性。
- 键盘操作、屏幕阅读器或辅助说明在企业系统中应被标注为 review 点。
