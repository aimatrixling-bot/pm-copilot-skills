# 产品拆解作战地图模板

> SKILL.md 引用：`完整 13 章模板 → references/output-template.md`
> 每个拆解产出必须按此模板组织。

## 设计原则

1. **每条结论都是推断而非描述**：不是"他们有 A 功能"，而是"他们做 A 功能的战略意图是 B，这对我们意味着 C"
2. **每条推断必须有证据**：标注来源和置信度（`[高置信]` / `[中置信]` / `[低置信]`）
3. **差异化优先**：最终产出不是"他们有多强"的恐惧报告，而是"我们从哪里切入"的作战地图
4. **AI 产品专属标注**：Layer 5 的推断必须标注 `[推断]`，与可观察事实区分
