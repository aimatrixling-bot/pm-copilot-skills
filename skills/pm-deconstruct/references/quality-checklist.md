# 交付前质量检查清单

> SKILL.md 引用：`完整清单 → references/quality-checklist.md`
> 交付前必须逐项检查，未通过项不得标注为完成。

---

## 通用检查（所有模式）

### 信息源标注

- [ ] 每个结论有信息源标注（⭐⭐⭐ / ⭐⭐ / ⭐ / ⚠️）
- [ ] 信息源可信度分级正确使用
- [ ] 第三方信息标注了 `[二手信息]`（如适用）

### 事实与推断分离

- [ ] 事实与推断严格分栏，无混用
- [ ] 无法拆分为"事实"和"推断"的结论已删除
- [ ] 每条推断标注了置信度（`[高置信]` / `[中置信]` / `[低置信]`）
- [ ] 推断逻辑链可追溯：[事实] → [因果推理] → [结论]

### 交叉验证

- [ ] 战略意图推断（L4）有 ≥2 个其他层的证据支撑
- [ ] 交叉验证矩阵已生成
- [ ] 矛盾信号未取平均值，已深入分析原因

### 信息缺口

- [ ] 所有无法获取的数据标注了 `[信息缺口]`
- [ ] 信息缺口未用推断填补
- [ ] 建议了验证方法

### 伦理边界

- [ ] Scope Gate 已执行（无非法手段内容）
- [ ] AI 逆向仅限公开可观察行为
- [ ] 无精确 Prompt 还原声称
- [ ] 无 ToS 违反内容

---

## Deep Dive 专项

### 层级完整性

- [ ] 五层完整覆盖（L0-L4），无跳层
- [ ] 每层至少使用 2 个分析工具
- [ ] Layer 5 已评估触发条件（是否为 AI 产品）

### Layer 0 检查

- [ ] 产品姿态判断有依据（Sovereign / Transient / 混合）
- [ ] 市场定位图已生成
- [ ] 目标用户分三类（显性 + 隐性 + 明确不服务）

### Layer 1 检查

- [ ] 五秒测试完成（3 条印象）
- [ ] 导航解剖完成（每项标注战略意图）
- [ ] 信息架构图已生成（含深度标注）
- [ ] 反向用户旅程图已生成（含设计意图标注）
- [ ] 结论是"推断"而非"描述"

### Layer 2 检查

- [ ] 价值网络图已生成（所有角色价值分析）
- [ ] 商业模式画布已填写
- [ ] 业务规则清单已列出（每条标注战略意图）

### Layer 3 检查

- [ ] 增长回路图已画出（循环结构，非线性列表）
- [ ] AARRR 五环节分析完成
- [ ] 留存机制清单已列出
- [ ] 增长引擎类型已判定

### Layer 4 检查

- [ ] 时间旅行分析完成（版本历史 / 页面快照）
- [ ] 负空间分析完成（"没有做什么"）
- [ ] 外部信号至少覆盖 2 种类型
- [ ] 战略意图声明为一句话
- [ ] 信号证据链完整

### 产出完整性

- [ ] 使用 output-template.md 的 13 章结构
- [ ] 差异化机会清单已生成（可直接输入 pm-rice）
- [ ] 下一步衔接已标注

- [ ] Layer 0 产品身份卡片已生成
- [ ] 五秒测试完成
- [ ] 导航解剖完成
- [ ] 3 个最有价值的洞察已提取
- [ ] 1 个差异化机会已识别
- [ ] 1 条战略建议已给出
- [ ] 产出为 1 页纸 Quick Scan 摘要

## AI Teardown 专项

### Layer 5 完整性

- [ ] 六维度全覆盖（Prompt / Harness / Eval / Agent / 上下文 / 安全）
- [ ] 至少执行 5 个逆向测试协议用例
- [ ] AI 架构推断标注置信度 + 测试依据
- [ ] 交互主权模式已判定

### 测试协议覆盖

- [ ] Prompt 探测：至少 P-04（角色泄漏）+ P-06（格式限定）
- [ ] Harness 探测：至少 H-01（工具可见性）+ H-05（权限边界）
- [ ] Agent 探测：至少 A-01（任务分解）
- [ ] 主权探测：至少 S-01（默认主权）

### 产出格式

- [ ] Prompt 架构推断为"结构组件"而非"Prompt 猜测"
- [ ] 推断内容与可观察事实已区分
- [ ] 所有推断标注 `[推断]`

---

## Cross Compare 专项

- [ ] 2-5 个对比产品已确认
- [ ] 每个产品完成 Layer 0 扫描
- [ ] 至少选择 3 个 L2 关键维度横向对比
- [ ] 竞品快照对比表已生成
- [ ] "我们的切入点"已标注

---

## Pass 2 专项

### 增量标注

- [ ] 使用固定格式标注（[Pass 2 新增] / [修正] / [推翻] / [确认] / [补充]）
- [ ] 每个标注有理由说明

### 版本保留

- [ ] Pass 1 原始结论未删除（保留版本对比）
- [ ] 变更追踪表已生成

### 一致性

- [ ] Pass 2 修正与其他层无新矛盾
- [ ] 交叉验证矩阵已更新
- [ ] 信息缺口清单已更新
